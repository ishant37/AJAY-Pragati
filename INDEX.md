## 🎯 Common Tasks

### Starting the App
```bash
npm start
```
📖 See: **QUICK_START.md** → "Getting Started"

### Building for Production
```bash
npm run build
```
📖 See: **README.md** → "Build for Production"

### Customizing Colors
Edit `src/theme.js`
📖 See: **DESIGN_REFERENCE.md** → "Color Palette"

### Adding New Pages
1. Create file in `src/pages/`
2. Add route in `src/App.jsx`
3. Add link in `src/components/Navbar.jsx`

📖 See: **QUICK_START.md** → "Add New Pages"

### Modifying Dashboard Data
Edit `src/pages/Dashboard.jsx`
📖 See: **SUMMARY.md** → "Customization Guide"

### Changing Chart Data
Edit `src/pages/Analysis.jsx`
📖 See: **SUMMARY.md** → "Modify Charts"
